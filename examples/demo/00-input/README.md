# 00-input —— 原始素材

放两样东西，以及一份清单。

## 放什么

| 文件 | 说明 |
|------|------|
| `raw.mp4`（名字可改） | **已经粗剪拼接完成、不含任何文字与特效**的视频 |
| `raw.srt`（名字可改） | 对应的字幕文件。**只取它的文本**，时间戳一律不信任 |

> 音频处理范围仅限「对齐必需」：抽 16kHz 单声道 wav。
> 降噪 / 响度归一 / BGM 分离 / 音频可视化**明确不做** —— 音质差会让对齐置信度低，
> 届时走「阻断 → 人工处理」那条已通的路径，而不是在这里堆预处理。

## `source.json` 清单

```jsonc
{
  "video": "raw.mp4",          // 相对本目录的文件名
  "srt": "raw.srt",
  "fps": 30,                   // 顶层固化：改 fps 必须重新烘焙
  "durationInFrames": 900      // 成片总帧数 = <Composition> 的 durationInFrames
}
```

`durationInFrames` 是校验项 #10「composition 尾部截断」的依据。
**它不是可选项** —— 填 0 会让该检查形同虚设，而 Remotion 对超长 item 是
**静默截断、不报错不打日志**的，成片少一截而全链路无感。

## 注意

- 媒体文件（`*.mp4` / `*.srt` / `*.wav` …）默认被 `.gitignore` 排除。要版本化请走 git-lfs。
- 本目录**不可变**：`align` 跑完之后不要回头改这里的素材。
  改了就必须从 `01-align` 起重跑，`02`–`06` 全部作废。

# perceive —— 抽帧、主体检测与安全区生成

> **管线位置**：第 2 步 / 共 5 步
> **上游**：`00-input/`（视频）+ `01-align/`（词级时间戳）
> **下游**：`02-perceive/` → 供 `storyboard` 起草与 `validate` 判定

本阶段解决的核心问题是**硬约束 1：motion graphic 出现时不得遮挡主体**。
它不判「图形之间打不打架」（那是 C4 的事），只判「图形会不会压到主体」。

## 何时触发

- `align` 门控已通过（`01-align/` 就绪）时。
- `02-perceive/` 已存在时默认不重跑；只有 `00-input/` 或 `01-align/` 变了才重跑。

## 核心职责

1. **抽帧** —— 每 1.5s 抽关键帧（**可调，是参数不是固定值**）。
2. **主体检测** —— 人物 bbox → 时空平滑 → 归属判定。
3. **手持物 / B-roll 检测** —— 按 shot 级累积。
4. **安全区 + 区域预算数据生成**。

## 铁律

### 1. 遮挡容忍度是向量，不是标量

不能用单一「最大遮挡比例」。各级区域的遮挡预算彼此独立，**算的是「从各级区域各拿了多少额度」，总和超预算才报错** —— 不是判「有没有相交」。

| 区域 | 遮挡预算 | 判定方式 |
|------|----------|----------|
| 人脸 / 头肩 | **0%** | person bbox 上部 + 关键点检测 |
| 手持物 | **≤ 20%** 面积 | 手部关键点邻域 + 局部显著性 |
| B-roll 主体 | **≤ 30%** 面积 | shot 级显著性峰值区 |
| 其余区域 | 无限 | — |

### 2. 安全区推导三原则

1. **安全区 ≠ 主体 bbox，取 bbox 上部。** 人脸头肩不可压，腿部以下压一下无妨。拿全 bbox 当禁区会过度收紧画面。
2. **按 shot 取并集，不逐帧跟随。** shot 内取并集后外扩固定 margin。**必须让 motion 可行域在一个 shot 内保持稳定** —— 否则动效会跟着人一起飘，与硬约束 3 的交叉叙事冲突。
3. **主体不在场的 shot → 安全区为空。** B-roll 空镜时全画面均为可行域。没有主体就不存在遮挡问题。

### 3. 主体归属走「自动初筛」，编辑页只是兜底

流程：每帧候选 bbox → 时空平滑剔除抖动与偶发误检 → **面积最大 + 中心先验**自动初筛。

素材已确认「除 B-roll 外基本是同一人」，误判概率本就低，因此**大部分镜头无需人工介入**。

**低置信时必须标记**，不要硬选一个：

- 该 shot 主体框标 `lowConfidence: true`
- **不阻断** pipeline
- 在 `04-validate` 报告里出 `W-F6-01` warning：「shot X 主体未确」
- 人工在 `06-review/confirmed.json` 里补 `subjectBox` 覆盖后才算确定

### 4. 手持物检测走 shot 级时间累积，不做逐帧跟踪

素材条件是「小物品、变化不大」。逐帧跟踪会因**手指交叠、换手**剧烈抖动，shot 内累积统计天然抗噪。

做法：手部关键点定位 → 邻域显著性 → 在整个 shot 内累积证据 → 输出稳定的讲解物 box。

### 5. B-roll 走独立通路，不要求人工标注

按 **shot 显著性峰值区**自动框出主体即可。产品特写与展示类镜头通常单镜头单焦点，自动框足够。
此类镜头的区域等级为「B-roll 主体」（≤ 30% 预算）。

### 6. 抽帧密度是参数

1.5s 是默认值，**可提问改密/疏**。密度决定的是检测样本量，与「主体在 shot 内位置稳定」这件事无关 —— 不要把密度当成精度瓶颈去死抠。

## 必须停条件

**无硬阻断。** 本阶段不允许因为检测置信度低而停下整条 pipeline —— 低置信走 `lowConfidence` 标记 + warning 通道，交给人工在编辑页兜底。

唯一必须停的情况：**输入缺失**（`01-align/` 不存在或门控未通过）→ 立即停，不得跳过 `align` 直接感知。

## 产物（落 `02-perceive/`）

文档对 `02-perceive/` 的规定是四类数据：**抽帧（1.5s 可调）+ 主体检测 + 手持物检测 + B-roll 检测 + footprint**。
**文档未点名文件名** —— 下表文件名为本 Skill 的实现建议，可调整，但四类内容不得缺失。

| 文件 | 对应文档要求 | 内容 |
|------|------------|------|
| `frames/` | 抽帧 | 抽帧图（默认每 1.5s，可调） |
| `subject.json` | 主体检测 | 每 shot 的主体框 + 安全区 + `lowConfidence` 标记 |
| `handheld.json` | 手持物检测 | shot 级累积出的讲解物 box |
| `broll.json` | B-roll 检测 | B-roll shot 的显著性峰值区 |
| `regions.json` | footprint 依据 | 各级区域的**预算占用基线**（供 validate 算额度） |
| `shots.json` | —（本 Skill 补充） | shot 边界切分，上述几项的公共索引 |

> **footprint 的最终归属是 `storyboard.json` 的 item，不是本阶段的独立文件。**
> D 分支已明确「不新增任何文件格式」—— 主体安全区与 footprint 同样走 `storyboard.json` + 渲染后测量两条路。
> 本阶段产出的 `regions.json` 只是 **storyboard 起草 footprint 时的依据**，不要为感知产物另立契约，那会让产出物分裂。

## 失败与退出码

| 情形 | 处置 |
|------|------|
| `01-align/` 缺失或门控未通过 | **停**，退出码 `1` |
| 参数错（抽帧密度非法等） | 退出码 `2` |
| 检测全部失败（无可用帧） | 退出码 `4`，如实报错，不伪造框 |
| 超时 / 中断 | 退出码 `5` / `130` |

**禁止**：检测不出来时随手编一个 bbox 糊过去。宁可标 `lowConfidence: true` 交人工。

## 落盘检查清单

- [ ] 抽帧密度已记录（实际用的值，不是默认值）
- [ ] 主体归属已按「面积最大 + 中心先验」初筛，低置信项已标 `lowConfidence: true`
- [ ] 安全区取的是 bbox 上部，且**按 shot 取并集**（没有逐帧跟随）
- [ ] 无主体的 shot 安全区为空，而非留一个残留框
- [ ] 手持物是 shot 级累积结果，**不是**逐帧跟踪输出
- [ ] B-roll 按显著性峰值区自动框，未要求人工标注
- [ ] 各级区域预算基线数据齐备（人脸 / 手持物 / B-roll）
- [ ] 未修改 `00-input/` 与 `01-align/`（不可变快照）

# 08 · 运行指南

## 1. 环境要求

| 项 | 要求 | 说明 |
|----|------|------|
| Node.js | **22.19+ / 24+** | Remotion 官方硬要求（`.nvmrc`） |
| ffmpeg | 系统可用 | align 抽 wav / perceive 抽帧与切镜 / render 读分辨率 |
| whisper.cpp + 模型 | align 内置后端 | ~148MB；`npm run` 外用 [tools/setup-whisper.mts](file:///g:/VideoPipeline/tools/setup-whisper.mts) 安装 |
| YuNet 权重 | perceive 内置后端 | 230KB；权重不入库（`perceive-models/` 被忽略），换机需重新下载并校验 sha256（官方版 `ebafce4e…`，229,738 字节） |
| Remotion | 锁 `4.0.534` | `--save-exact`，禁 `^`；与全部 `@remotion/*` 同版本 |
| GPU 配置 | **必须 `--gl=angle`** | 4.0.x 漏了 Chrome Headless Shell 可能产出空白 canvas |

新机器先跑自检：

```bash
npm run doctor   # 一次说清缺什么、怎么补
```

## 2. 安装

```bash
npm install
npm run typecheck   # 可选：tsc --noEmit 确认类型干净
npm test            # 可选：vitest 全量测试
```

## 3. 标准五阶段流程

```bash
# 0. 建一个 job（生成 jobs/<id>/{00-input..06-review} 骨架 + source.json 模板）
npm run pipeline -- init --job my-first

# 1. 放素材：把「已粗剪拼接、无文字无特效的视频 + SRT」放进 jobs/my-first/00-input/
#    填好 source.json：{ video, srt, fps, durationInFrames [, width, height] }

# 2. 按序执行（01/02 为不可变快照，返修改第 N 级则 N+1 级作废重跑；03/04/05 每次重算）：
npm run pipeline -- align      --job my-first     # 门控不过会停，等人工确认
npm run pipeline -- perceive   --job my-first     # 低置信只告警不阻断
npm run pipeline -- storyboard --job my-first
npm run pipeline -- validate   --job my-first     # 有 error 停（退出码 1）
npm run pipeline -- render     --job my-first     # 启动闸 + 渲染

# 3. 预览
npm run studio
```

### 全部 CLI 选项

| 选项 | 说明 |
|------|------|
| `--job, -j <id>` | job 标识（除 init 外必填） |
| `--jobs-dir <dir>` | job 根目录，默认 `jobs` |
| `--interval <sec>` | 抽帧密度，默认 1.5s |
| `--force` | 忽略不可变快照守卫，强制重跑本阶段 |
| `--dry-run` | `render` / `review` 通用：只做 C6 映射与启动闸检查，不真渲染、不真起 Studio |
| `--no-subtitle` | align 专用：声明本片不做字幕对齐（只能用 `abs:` 锚点，字幕模板不可用） |

### 退出码

`0` 可交付 / `1` 校验没过（**含 `StageBlockedError`**，如门控不过、must_review 未看片）/
`2` 参数错（`ConfigError`）/ `3` 版式✗（🔴 **有定义但无任何返回路径，别据此判流**）/
`4` 渲染失败 / `5` 排队超时 / `6` 内部错误 / `130` 中断。

## 4. 端到端跑通示例（不需要真实素材）

[examples/demo](file:///g:/VideoPipeline/examples/demo) 是 fixture 备好的完整 job，
用来验证管线本身：

```bash
npm run pipeline -- storyboard --job demo --jobs-dir examples
npm run pipeline -- validate   --job demo --jobs-dir examples
npm run pipeline -- review     --job demo --jobs-dir examples --dry-run
npm run pipeline -- render     --job demo --jobs-dir examples --dry-run
```

⚠️ P1-a 审核闸：demo 会产出一条 must_review 条目（`typo-main/002`）—— `render`
在其被确认前 exit 1。确认写法见 `06-review/confirmed.json` 的
`acknowledgedReview` 数组（README 有完整示例）。

预期：`validate` 报 **0 error / 2 warning**（`summary.checked = 18`，
`summary.extra` 含 `W-D3-01` / `W-F6-01` 两条），
两条 warning 均为 `W-F6-01`（示例故意把 s2 镜头与其人脸区标低置信，演示人工兜底通道）。

## 6. 起草稿（motionboard.json）怎么写

🔴 **文件名是 `03-storyboard/motionboard.json`，不是 `draft.json`**。`draft.json` 是
Wave 5（2026-10-21）之前的旧名，代码已完全不读 —— 按旧名起草会被**静默忽略**，
管线会自己生成一份节奏表底稿再烘焙，看起来"跑通了"但你的稿子没进成片。

模型/人工只做三件事：**写锚点、挑意图或钉死模板、填文字**。禁写坐标/帧数/颜色/CSS。

```jsonc
// 03-storyboard/motionboard.json 的 item 层示意
{
  "_author": { "anchor": "word:37", "offset": "-8f" },  // 必填：word:/cue:/abs:；负偏移=抢拍
  "intent": "new-topic",                                 // 与 motion 二选一（受控词表）
  // "motion": "typography/lower-third@1.0",             // 或钉死模板 id
  "confidence": 0.82,                                    // 必填：闸2 输入
  "featuredText": "张三 · 产品负责人",                     // 可选：模型提炼文案
  "params": { "title": "张三", "subtitle": "产品负责人" },   // 仅钉死条目写，#16 校验
  "exclusive": "lower-third",                            // 可选：互斥组
  "footprint": [0.06, 0.72, 0.42, 0.16],                 // 可选：覆盖模板默认
  "note": "开场自我介绍，压在左下角避开人脸",              // 可选：人读备注，零消费
  "carrier": { "template": "carrier/split-frame@1.0", "params": {} }  // 可选：载体退让声明
}
```

⚠️ `intent` 与 `motion` **必须二选一**（`assertMotionboardKeys` 强制）；写 `handoffIn`
会直接 `ConfigError`（该字段已于 2026-10-15 删除，入场方式请用 `params.enter`）。

可用的 motion id：**11 个内置**（见 [06 · 模板体系](06-模板体系.md) §4）+
8 个 `custom/*@1.0`（spec 驱动，见 §5）。用未注册 id 会在校验/渲染时报错。

## 7. 外部命令覆盖（可选）

```bash
# 强制对齐：把 {fps, words, cues} 写到 {out}
export ALIGNER_CMD="python tools/align.py --wav {wav} --srt {srt} --out {out} --fps {fps}"

# 感知：写出 {out_dir}/shots.json 与 {out_dir}/regions.json
export PERCEIVER_CMD="python tools/perceive.py --video {video} --frames {frames_dir} --out {out_dir} --fps {fps} --interval {interval}"

# YuNet 模型路径覆盖
export PERCEIVE_MODEL=/path/to/yunet.onnx
```

不配走内置；内置也跑不通（缺模型/缺 ffmpeg）时**显式报错退出码 2，绝不伪造结果**。

## 8. 测试与质检

```bash
npm run verify          # 🔴 三段验收：typecheck + test + demo 端到端（约 2 分钟）
npm test                # vitest 全量（57 个测试文件 / 852 项）
npm run test:watch      # watch 模式
npm run typecheck       # tsc --noEmit
npm run doctor          # 依赖健康自检
npm run placeholders    # 列出全部占位值（待校准阈值清单）
npm run determinism -- --job demo --jobs-dir examples   # 双渲像素一致性（D5.6）
```

🔴 **`npm run verify`（A3，2026-10-26）**：一条命令回答「README 的第一条流程现在还成立吗」。
三段任一失败即非零退出：

| 段 | 内容 | 失败含义 |
|---|---|---|
| `typecheck` | `tsc --noEmit` | 类型契约破裂 |
| `test` | vitest 全量（含**跨阶段集成测试** `tests/pipeline-e2e.test.ts`） | 单元或阶段串联失效 |
| `e2e-demo` | 复制 `examples/demo` 到临时目录，用 **CLI** 真跑 `storyboard → validate(18) → review --dry-run → render --dry-run` | 用户实际敲的命令跑不通 |

e2e 段有一条**双向断言**：demo 故意留一条 `must_review`，所以 `render` **先必须被拦下**，
补 `confirmed.json` 后**必须放行** —— 闸门「松了」和「卡死」都能被这条抓住。
快速冒烟：`npm run verify -- --skip-test`（约 20 秒）。

🔴 **`npm run determinism`（D5.6，2026-10-26）**：对抽样帧各渲**两次**，比 PNG **字节**。
同像素同编码 ⇒ 字节相同是比像素更强的判据，且不必引图像解码依赖。
- 默认从 `storyboard.json` 取 **item 区间中点**作为抽样帧（保证抽到真有动效的画面）；
  也可 `--frames 120,900` 显式指定。
- 退出码：`0` 全一致 / `1` 有不一致（确定性红线破）/ `2` 前置缺失（先跑 `render --dry-run`）。
- ⚠️ **不进 `npm test`**：一帧约 12–16 秒（含 bundling），3 帧 ×2 次 ≈ 1 分钟。
- ⚠️ 若多个抽样帧画面**彼此相同**，脚本会额外警告「证据力弱」——
  那说明抽到了空帧（overlay 区间外），空画面比空画面必然一致。

测试覆盖：校验体系（逐项）、模板渲染、文本对齐、文本溢出、SRT、烘焙、调度、门控、
注册表、韵律表、spec 契约/渲染、载体、配方卡契约、输入指纹等（与 [07 · 依赖关系](07-依赖关系.md) §6 的清单对应）。
具体断言数以当次 `npm test` 输出为准。

## 10. 常见问题排查

| 症状 | 排查方向 |
|------|----------|
| 渲染出空白 canvas | 漏了 `--gl=angle`；或 GPU/Chrome Headless Shell 环境问题（`npm run doctor`） |
| `align` 退出码 1 | 门控不过（均值 <0.60 / 低置信 >30% / alignedRatio <0.80，🔴均为待校准初值）。人工确认：写 `06-review/confirmed.json`（`stage:"alignment"`）；若降级 cue 级，`storyboard.meta.anchorMode` 标 `"cue"` |
| `storyboard` 报前置产物缺失 | 上游 `01/02` 没跑或被 `--force` 弄脏；跨级引用被禁 |
| `validate` 全是 `E-P1-*` | draft 的 `params` 写错：未知键/缺必填/类型不符（不做隐式转换，`"1.08"` ≠ `1.08`） |
| `render` 拒绝启动 | ① validate 报告 `ok=false`；② fullscreen 未确认（缺 `confirmed.json` 的 `stage:"render"` + `acknowledgedFullscreen`）；③ Remotion 版本漂移（重装精确 `4.0.534`）；④ fps 漂移 |
| 模板渲染成灰框 | 该模板**只有声明、没有组件**（Placeholder 刻意暴露）；`custom/*` 检查 `templates/specs/*.json` 是否装载（CLI 启动时会自动装） |
| 抽帧内容与帧号错位 | 内置感知器已用 `-fps_mode passthrough` 防；外部感知器须自行保证 |
| 成片比例不对 | `source.json` 的 `width/height`（同时填或同时省略）；省略时用 ffprobe 读，兜底 1920×1080 |

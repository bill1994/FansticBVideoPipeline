# 02 · 模块职责

按 `src/` 五大目录逐文件说明。行数规模为约数，职责描述基于源码文件头注释与实际逻辑。

## 1. `src/cli.ts` —— 统一入口（约 264 行）

五阶段命令 + `init` 的参数解析、调度分支、门控输出与退出码映射。

- **启动时序**：`assertRegistryValid()`（模板注册表契约校验）→ `loadSpecsFromDisk()`
  （装载 `templates/specs/*.json`，目录不存在静默跳过）→ 解析参数 → 分发阶段。
- **命令**：`init` / `align` / `perceive` / `storyboard` / `validate` / `render` / `help`。
- **选项**：`--job/-j`（除 init 外必填）、`--jobs-dir`（默认 `jobs`）、`--draft`、
  `--interval`（抽帧密度秒）、`--force`（忽略不可变快照强制重跑）、`--dry-run`、
  `--no-subtitle`（声明无字幕对齐，M-1g）。
- **退出码**：`0` 可交付 / `1` 校验没过 / `2` 参数错 / `3` 版式✗ / `4` 渲染失败 /
  `5` 排队超时 / `6` 内部错误 / `130` 中断。

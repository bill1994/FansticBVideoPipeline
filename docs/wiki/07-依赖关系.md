# 07 · 依赖关系

## 1. 内部模块依赖图

方向：箭头指向被依赖方。分层清晰，**`core` 不依赖任何上层**
（唯一例外纪律见下「占位值注册表」）。

```
                      ┌─────────────┐
                      │   cli.ts    │  统一入口
                      └──────┬──────┘
             启动序：assertRegistryValid → loadSpecsFromDisk
                             │
      ┌──────────┬───────────┼────────────┬───────────┐
      ▼          ▼           ▼            ▼           ▼
 ┌────────┐ ┌────────┐ ┌──────────┐ ┌─────────┐ ┌──────────┐
 │stages/ │ │validate│ │templates/│ │ core/   │ │remotion/ │
 │五阶段  │ │18项校验│ │契约+注册 │ │契约/IO  │ │渲染工程  │
 └───┬────┘ └───┬────┘ └────┬─────┘ └─────────┘ └────┬─────┘
     │          │           │                         │
     └──────┬───┴───────────┴─────────────┬───────────┘
            ▼                             ▼
        ┌───────┐                    ┌────────────┐
        │ core/ │◄───────────────────│templates/  │
        └───────┘   (types, spec)   │types/spec  │
                                    └────────────┘
```

### 逐向依赖说明

| 依赖方 → 被依赖方 | 内容 |
|-------------------|------|
| `cli.ts` → `core/config` | `STAGES`、`DEFAULT_JOBS_DIR` |
| `cli.ts` → `core/exit-code` | `EXIT`、`exitCodeFor`、错误类 |
| `cli.ts` → `core/io` / `core/log` | job 目录、输出 |
| `cli.ts` → `templates/registry` + `core/spec-loader` | 启动期注册表校验与 spec 装载 |
| `cli.ts` → `stages/*` | 五阶段执行函数 |
| `stages/*` → `core/*` | types / config / io / log / bake / report / confirmed / silence / doctor |
| `stages/validate.ts` → `validate/*` | `buildContext`、`runValidation` |
| `stages/render.ts` → `validate/occlusion` | `resolveScene`（渲染期重算遮挡消解） |
| `stages/render.ts` → `templates/types` | `isCarrierScope`（C6 双栈分离）、`TemplateDeclaration` |
| `stages/render.ts` → `remotion/caption` + `remotion/carrier-synth` | `toCaptionData`、`synthesizeCarrierTracks` —— **这是 stages 层唯一伸进 remotion 层的手**：render 负责组装 Remotion 的 input props |
| `stages/render.ts` → `node:child_process` | `execFileSync('npx remotion render ...')` —— remotion 运行时**不**被 stages 直接 import，通过子进程调用 |
| `validate/*` → `core/report` / `core/types` / `core/config` | 报告组装、数据契约、阈值 |
| `templates/*` → `core/types` / `core/spec` | `Footprint`、`MotionSpec` |
| `remotion/*` → `core/types` / `templates` 契约 | 渲染层消费 storyboard 与模板声明（运行时经 input props，编译期只取类型） |

### 依赖方向的两条纪律（写在代码注释里的教训）

1. **禁止 `core → stages` 反向依赖**：占位值注册表（`core/placeholders.ts`）要引用
   `HANDHELD_EXPANSION`、`SALIENCY_TARGET_AREA_RATIO` 等常量，因此这些常量定义在
   `core/config.ts`、`stages/region-derive.ts` 只 re-export —— 单一真源 + 不破坏 import。
2. **抄一份就会漂移**：本项目已三次栽在「同一概念两处实现」（字号表、DUR.exit、
   载体映射表）。字号真源收进 `TemplateDeclaration.textMetrics`、载体退让改为逐 item
   `carrier` 字段（D4-t2 废除全局映射表），都是这条教训的产物。

## 3. 外部工具依赖

| 工具 | 谁用 | 说明 |
|------|------|------|
| **ffmpeg**（系统 PATH） | align（抽 16kHz wav、silencedetect）、perceive（`scdet` 镜头切分、抽帧 select/scale/pad）、render（ffprobe 读分辨率） | 缺失 → 显式报错退出码 2，不伪造结果 |
| **whisper.cpp**（`whisper.cpp/`，模型 ~148MB） | align 内置对齐器 | 只采信 segment 层时间；模型权重不入库 |
| **YuNet ONNX 权重**（`perceive-models/`，229,738 字节，sha256 `ebafce4e…`） | perceive 内置人脸检测 | 经 onnxruntime-node 推理；`PERCEIVE_MODEL` 可覆盖路径；下载后须校验 sha256 |
| **Chrome Headless Shell** | Remotion 渲染 | **必须显式 `--gl=angle`** —— 4.0.x 漏了可能产出空白 canvas |
| Node.js | 运行时 | **22.19+ / 24+**（Remotion 硬要求，`.nvmrc`） |

## 4. 环境变量

| 变量 | 作用 | 缺省行为 |
|------|------|----------|
| `ALIGNER_CMD` | 外部强制对齐器，占位符 `{wav} {srt} {out} {fps}`；须往 `{out}` 写 `AlignWords`（+可选 `alignedRatio`） | 走内置 whisper.cpp + DP 对齐 |
| `PERCEIVER_CMD` | 外部感知器，占位符 `{video} {frames_dir} {out_dir} {fps} {interval}`；须写 `{out_dir}/shots.json` 与 `regions.json` | 走内置 scdet + YuNet |
| `PERCEIVE_MODEL` | 覆盖 YuNet 模型路径 | `perceive-models/` 下默认权重 |

`.env.example` 提供模板；两个外部命令**都不配也能跑**（内置实现兜底）。

## 5. 渲染期的「非 import」依赖链

```
stages/render.ts
  ├─ 写 05-render/render-props.json（input props）
  └─ execFileSync('npx remotion render src/remotion/index.ts Overlay <out> --gl=angle')
        └─ src/remotion/index.ts → Root.tsx → Overlay.tsx
              ├─ input props.storyboard / stacks / carrierTracks / caption / templates
              ├─ MotionItem → getTemplateComponent → 模板组件 | SpecRenderer | Placeholder
              └─ carrier.tsx → composeCarrierTimeline（背景链）
```

即：**构建期（stages）与渲染期（remotion）只通过 `render-props.json` 这份 JSON 契约耦合**，
编译期共享的只有类型与少量工具函数（`toCaptionData`、`synthesizeCarrierTracks`）。

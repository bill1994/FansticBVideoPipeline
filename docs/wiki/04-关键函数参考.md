# 04 · 关键函数参考

按模块列出对外导出的关键函数与组件。签名以实际源码为准（链接指向源码位置）；
此处目的是「查得到、看得懂」，不是逐行复制。

## 1. CLI 层（[src/cli.ts](file:///g:/VideoPipeline/src/cli.ts)）

| 函数 | 签名 | 职责 |
|------|------|------|
| `parseArgs` | `(argv: string[]) => Args` | 解析 `--job / --jobs-dir / --interval / --force / --dry-run / --no-subtitle`；未知参数抛 `ConfigError` |

### 错误与退出码

| 导出 | 位置 | 职责 |
|------|------|------|
| `EXIT` | [exit-code.ts](file:///g:/VideoPipeline/src/core/exit-code.ts) | `0 可交付 / 1 校验没过 / 2 参数错 / 3 版式✗ / 4 渲染失败 / 5 排队超时 / 6 内部错误 / 130 中断` |
| `exitCodeFor(e)` | 同上 | `ConfigError→2`、🔴 **`StageBlockedError→1`**（`VALIDATION_FAILED`，不是 3）、`RenderFailedError→4`、未知→6（只有未知才打栈）。`EXIT.LAYOUT_INVALID=3` 有定义但无任何返回路径 |
| `ConfigError` / `StageBlockedError` / `RenderFailedError` | 同上 | 语义化错误类；与项级 `E-*/W-*` 码**两套并存不混用** |

## 3. stages 层

| 函数 | 位置 | 签名要点 |
|------|------|----------|
| `runAlign` | [align.ts](file:///g:/VideoPipeline/src/stages/align.ts) | `({jobId, jobsDir, force}) → {report: AlignReport, gatePassed: boolean}`；流程：读 source.json → ffmpeg 抽 16kHz wav →（外部 `ALIGNER_CMD` 或内置）→ 静音探测 → 门控判定 → 写 `words.json` + `align-report.json` |

| `runRender` | [render.ts](file:///g:/VideoPipeline/src/stages/render.ts) | `({jobId, jobsDir, dryRun?}) → {propsFile: string}`；启动闸 `renderGate()` 三道（validate ok / fullscreen 确认 / 🔴 must_review：preview-props + hash 未漂移 + acknowledgedReview）+ `assertVersionPinned` → 遮挡消解 `resolveScene` → C6 双栈分离 → 写 render-props.json → `execFileSync('npx remotion render ... --gl=angle')`。⚠️ fps 漂移不在本函数，在 `buildContext` |

## 1. 组织方式

- **构建期校验 = 纯函数 JSON→JSON**：不渲染、逐项独立判定、不剔除非法 item
  （剔除会让报告随执行顺序变化并吞掉其他项的问题）。
- **结构性错误不降级**：`assertStructuralIntegrity`（如 `handoffTo` 指向不存在的 track）
  抛 `ConfigError` → 退出码 2 —— 「配置错」不能伪装成「内容没做好」。
- 🔴 **输入指纹守卫（P0-4，2026-10-26）**：`buildContext` 里的 `assertInputsUnchanged`
  比对 `storyboard.meta.inputsHash` 与当前 `motionboard.json` / `words.json` 算出的值，
  不一致 → `ConfigError`（退出码 2），提示重跑 `storyboard`。
  挡的是「改完稿子忘了重跑」——此时校验的是**旧绑定**，报告全绿而成片与稿子对不上。
  与 mTime 版 `assertStageOrderIsSane` **并存**：mTime 管阶段先后（会被 `cp`/`git checkout` 骗），
  本守卫管内容是否变过。旧产物无该字段时跳过。
- **有 error 必须停**（退出码 1），warning 不拦。
- **渲染期兜底三类（2026-10-26 已接线）**：`E-RT-01/02/03`（字体未加载 / Canvas 未挂载 /
  GPU 上下文失败）。实现方式：`runRender` 用 `spawn` 流式转发子进程输出（保留实时进度）
  并累积尾部 200KB 文本，失败时经 `classifyRenderFailure()` 子串分类，写进
  `05-render/render-report.json` 的 `items`（`stage:"render"`）+ `failure`。
  ⚠️ 判据是子串匹配（Remotion 无结构化错误码），**三条都不命中时 `classified: null`**，
  如实标「失败但未归类」，不硬塞一个像模像样的码。
  渲染失败仍以退出码 4 中止，但**产物里会留下可对账的记录**（此前什么都不留）。
- **活清单纪律**：增补校验项须先改 `docs/decisions/OPEN-DECISIONS.md`，不得只改代码。

**清单准入规则**：输入在本阶段可读 / 纯结构化判定 / 渲染前就该阻断 —— 三条全中才进；
**例外只应该有 D3 这一条**。

## 4. 人工审核队列（reviewQueue）

P2 裁决（2026-10-19）：产路地板把 `custom` 抬到 `must_review` 之后，此前没有任何消费者。
`runValidation` 末尾把 `decision.review === 'must_review'` 的条目收进
`report.reviewQueue`（`{ref, motion}[]`），作为「该看哪几条」的清单落地。

⚠️ 它**不是校验项**：不进 `checked`、不影响 `ok`、不产 `ReportItem`。

## 5. 渲染启动闸（validate 之外的拦截面）

`renderGate()`（[stages/render.ts:49](file:///g:/VideoPipeline/src/stages/render.ts)，由 `runRender` 首行调用）
内含**三道**，返回非 `null` 即抛 `StageBlockedError`（🔴 **退出码 1**，`EXIT.VALIDATION_FAILED`）：

1. `04-validate/validate-report.json` 存在且 `ok === true`；
2. fullscreen 场景要求 `06-review/confirmed.json` 含 `stage:"render"` + `acknowledgedFullscreen`
   （类型是 **item ref 字符串数组**，如 `["fs/000"]`，**不是 `true`**）；
3. 🔴 **`must_review` 硬闸**（P1-a，2026-10-22）：先要求 `06-review/preview-props.json` 存在，
   且其 `storyboardHash` 与当前 `storyboard.json` 一致（review 后改过 storyboard ⇒ 看片确认作废）；
   再要求 render 记录的 `acknowledgedReview` 数组覆盖全部 must_review ref。

闸之外还有一道独立自检：`assertVersionPinned()`（Remotion 锁 `4.0.534` 禁 `^`）。

⚠️ **fps 漂移不在 render 闸里** —— 它位于 `src/validate/context.ts` 的 `buildContext()`
（比较 `source.fps` / `alignWords.fps` / `bake-report.fps` 三者与 `storyboard.meta.fps`），
render 通过 `composeRenderProps()` 建 ctx 时被动触发。

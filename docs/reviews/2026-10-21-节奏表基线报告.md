## 4. validate 唯一 error：E-D4-01（生成器结构性缺陷）

```
E-D4-01 [motion/011, r-handheld-s14] handheld 区域被遮挡 27.6%，超预算 20%；
        三级退让用尽 —— item 未声明载体档（carrier 字段），退让无法启动
```

**归因**：`synthDraft` 只消费 cues（经节奏表），**不读 `02-perceive/regions.json`** ——
footprint 全部取模板声明默认值，与 safeArea / 遮挡预算零联动；也不声明 `carrier` 退路。
这与 §3 的发现同根：**规则层对画面全盲**。
另有 1 条 warning `W-D2-01`（face 遮挡 15.3%）靠校验器就地平移消解 —— 侥幸在 face 预算 0% 内被救回，
handheld 这条 27.6% 平移后仍超 → 只能 error。

> 即：**内置生成器产出的 storyboard 当前无法直接过 validate**。这是比覆盖率更硬的缺陷，
> 修 motionboard/绑定器时必须让绑定层感知 regions 并声明 carrier 退路。

## 6. 对 motionboard intent 词表 v0 的直接输入

把 48 条 cue 里**语义上明显该配动效、但规则全漏**的类别拉出来（人工通读 SRT）：

| 语义类 | 例（本片实际句子） | 规则现状 |
|--------|--------------------|----------|
| 材质/配置点 | 「前掌是这个 EVA」被命中纯靠 repetition 凑对 | number/material 词表缺失 |
| 劣势对比结论 | 「它的存在感并不怎么样」「耐磨性也不怎么好」 | 「不怎么」类口语否定 contrast 词表未收 |
| 推荐结论 | 「不管是自穿还是送人都可以冲」 | 无 recommendation 类意图 |
| 总评/收束 | 「这双联名鞋有没有值回票价」 | definition 0 命中；总评句仅 cue 47 靠 closing 捡到 |

→ intent 词表 v0 应至少覆盖：`number` / `material-spec` / `contrast-verdict` /
`recommendation` / `question` / `closing-verdict` / `enum` / `repetition-term`（升强或改判定）。
同时 repetition 需重新设计：要么提为「全片关键词条 → tag-float 的正向意图」（本片 71% 命中率说明它是真信号，只是不该按现规则判），
要么收紧词频口径。

## 7. 结论与后续

1. **基线确立**：规则打底的现状 = 覆盖 25%、50% 落兜底模板、文案 4 类失败模式、validate 不过（E-D4-01）。
2. **「效果一般」的量化坐实**，且暴露了一个预想之外的更硬问题：**生成器画面全盲（不读 regions / 无 carrier）**。
3. 后续（对应 spec Open questions）：
   - intent 词表 v0 清单按 §6 拟定，与绑定映射一并对齐（一并校准纪律）
   - 绑定层必须消费 regions 并声明 carrier（否则 motionboard 路线照样撞 E-D4-01）
   - 绑定失败策略建议：显式 no-fits + 报告，不做静默降级（E-D4-01 的教训：降级/消解必须留痕）
   - 数字带（覆盖率目标）待精修层接入后按本基线对比另定
